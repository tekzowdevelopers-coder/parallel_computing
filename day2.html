🔬 Silicon & Hardware

Distributed Systems, GPU Grids & Hybrid HPC

How physical hardware scales from multi-core CPUs to distributed clusters and massively parallel GPU accelerators.

🧊

Shared Memory (OpenMP)

Day 1 Focus
Shared RAM (Central Refrigerator)
↓↓↓↓
Core 0 (Chef 0)
Core 1 (Chef 1)
Core 2 (Chef 2)
Core 3 (Chef 3)

All threads directly read and write the same address space. Fast pointer operations, but vulnerable to race conditions.

🌐

Distributed Memory (MPI)

Day 2 Focus
Branch 0 (Chennai) RAM 0 (Fridge 0)
⇄ MPI Network Messages ⇄
Branch 1 (Bangalore) RAM 1 (Fridge 1)

Each branch has its own private RAM. Chennai cannot touch Bangalore's fridge; they must exchange explicit network messages (MPI_Send / MPI_Recv).

SIMD / SIMT

Single Instruction, Multiple Data

💬 Analogy: Head Chef barks: "Everyone CHOP ONE TOMATO simultaneously!"
  • One instruction stream: CHOP
  • Different data points: Worker 1 has Tomato 1, Worker 2 has Tomato 2...
  • Silicon: AVX-512 vector units and GPU Warps (SIMT: Single Instruction, Multiple Threads).
MIMD

Multiple Instruction, Multiple Data

💬 Analogy: Four chefs prepare completely different dishes:
  • 👨🍳 Chef 0: Boils rice
  • 👨🍳 Chef 1: Fries chicken
  • 👨🍳 Chef 2: Prepares salad
  • 👨🍳 Chef 3: Bakes naan bread
  • Silicon: Multi-core CPUs and MPI clusters executing independent processes.
CPU (Host)

The Master Head Chef

A few (4–64) powerful cores optimized for sequential speed, branch prediction, and complex decision-making.

💬 Role: Manages overall business, orders ingredients, and coordinates workflow.
GPU (Device)

The Mass Assembly Factory

Thousands (1,000–10,000+) of lightweight cores designed for massive data-parallel mathematical throughput.

💬 Role: 10,000 workers peeling potatoes or chopping onions at blisteringly fast speed.

The Modern Supercomputer Pyramid: MPI + OpenMP + CUDA

World-class HPC clusters don't choose between paradigms; they combine all three into a single cohesive hierarchy.

MPI: Distributed Processes Across Cluster Nodes (Network Scale)
OpenMP: Multi-threading Across CPU Sockets & Cores (Node Scale)
CUDA GPU: Massive Parallel Kernels on Accelerators (Core Scale)
SIMD / Vectorization: 512-bit Registers within GPU/CPU Cores
