🔬 Hardware & Memory

Architectures, SIMD/MIMD & Memory Models

Understanding the silicon under the hood and the crucial difference between shared and distributed memory.

SIMD

Single Instruction, Multiple Data

💬 Kitchen Analogy: The Head Chef barks: "Everyone CHOP ONE TOMATO simultaneously!"
  • One instruction: CHOP
  • Multiple data streams: Worker 1 has Tomato 1, Worker 2 has Tomato 2, Worker 3 has Tomato 3...
  • Silicon implementation: Vector registers (AVX-512, NEON, GPUs).
  • Best for: Image pixel processing, vector math, audio processing.
MIMD

Multiple Instruction, Multiple Data

💬 Kitchen Analogy: Four chefs prepare completely different dishes:
  • 👨🍳 Chef 1: Boil rice (Instruction A, Data A)
  • 👨🍳 Chef 2: Fry chicken (Instruction B, Data B)
  • 👨🍳 Chef 3: Toss salad (Instruction C, Data C)
  • 👨🍳 Chef 4: Bake bread (Instruction D, Data D)
  • Silicon implementation: Modern Multicore x86 / ARM CPUs running independent threads (OpenMP model).
🧊

Shared Memory Architecture

OpenMP Model
Shared RAM (Central Pantry / Fridge)
↓↓↓↓
Core 0 (Thread 0)
Core 1 (Thread 1)
Core 2 (Thread 2)
Core 3 (Thread 3)

All threads share one common address space. Fast communication via pointers, but requires caution with race conditions!

🌐

Distributed Memory Architecture

Cluster Model
Node 1 (Branch 1) RAM 1
⇄ Network Messages ⇄
Node 2 (Branch 2) RAM 2

Separate physical computers (branches). Branch 1 cannot peek into Branch 2's fridge; they must pass explicit messages over the network.

Why Cache Matters: The Walking Chef Problem

If the central refrigerator (RAM) is 50 meters away, walking back and forth for every pinch of salt destroys throughput. Modern CPUs put small, ultra-fast memory right next to the core.

L1 Cache (Fastest, ~1-2 ns, KB) — Chef's Cutting Board
L2 Cache (~3-5 ns, Hundreds KB) — Personal Prep Shelf
L3 Cache (~10-20 ns, Shared MB) — Kitchen Pass Counter
Main Memory RAM (~60-100 ns, GB) — Central Cold Storage

⚠️ The Cache Coherence Dilemma

Suppose Chef 1 updates the secret salt quantity on their cutting board. Chef 2 still reads their local stale copy. Hardware uses cache coherence protocols (MESI) to keep local caches synchronized automatically.
